# 写真の置き場所

`index.html` は、このフォルダの下記ファイル名で写真を読み込みます。
同じファイル名でこのフォルダに入れるだけで、サイトに反映されます。

| ファイル名 | 表示される場所 | 推奨サイズ・比率 |
| --- | --- | --- |
| `coach-mochimaru.jpg` | COACHページ / 持丸 春聡 | 縦長 3:4（例 1125×1500） |
| `coach-takeuchi.jpg` | COACHページ / 竹内 悠悟 | 縦長 3:4（例 1125×1500） |
| `product-spasub.jpg` | STOREページ / スパサブ | 正方形 1:1（例 1080×1080） |
| `ogp.png` | SNS・LINEでシェアされたときのプレビュー画像（OGP） | 1200×630 固定 |

- ファイルが無いあいだは、これまでどおりグレーのしま模様（プレースホルダー）が表示されます。
  写真を入れると自動でそちらに切り替わります。
- 枠に合わせて中央基準で切り取られて表示されます（`object-fit: cover`）。
  顔や商品が端に寄っていると切れることがあるので、中央寄りの写真がおすすめです。
- 拡張子は `.jpg` です。`.jpeg` や `.png` を使う場合は `index.html` の `src="images/..."` も合わせて書き換えてください。
